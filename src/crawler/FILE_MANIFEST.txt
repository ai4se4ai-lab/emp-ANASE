================================================================================
USAGE WORKFLOW
================================================================================

1. INSTALL
   $ make install

2. CONFIGURE
   $ cp .env.example .env
   # Edit .env with your API credentials
   # Edit config.yaml with your search parameters

3. COLLECT
   $ make collect              # All platforms
   $ make collect-so           # Stack Overflow only
   $ make collect-reddit       # Reddit only

4. VALIDATE
   $ make validate             # Verify URLs and content

5. ANALYZE
   $ python analysis_template.py

ETHICAL CHECKLIST
================================================================================

Before running collection:
[ ] API keys obtained legitimately from all platforms
[ ] Rate limits configured appropriately
[ ] Discord collection disabled OR server owner permission obtained
[ ] IRB approval obtained for survey component
[ ] Informed consent mechanism ready
[ ] Data anonymization pipeline configured
[ ] Replication package plan established (Zenodo/Figshare)

================================================================================
VERIFICATION STATUS
================================================================================

This framework was designed to address the verification failures identified
in the original paper:

ORIGINAL PROBLEM                    FRAMEWORK SOLUTION
----------------                    ------------------
Unverifiable GitHub discussions     Real-time URL validation via data_validator.py
Fabricated academic citations       No citations generated; only raw data collected
Impossible "753 unique developers"  Cross-platform deduplication explicitly documented
                      as impossible without identity linking
Missing replication package         Automated export to standardized CSV + JSON
No statistical tests                analysis_template.py with Kruskal-Wallis, 
                                  Mann-Whitney U, Spearman correlation
No confidence intervals             Inferential statistics included in analysis
